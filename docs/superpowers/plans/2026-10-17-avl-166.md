# AVL-166 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a fundação executável e validada do monorepo PARTSAGRICOLA.

**Architecture:** Next.js para as três interfaces, Fastify para API/Auth, Node para worker e packages TypeScript compartilhados. PostgreSQL unificado é a fronteira de catálogo; efeitos externos ficam em providers/n8n.

**Tech Stack:** pnpm, Turborepo, TypeScript strict, Next.js, Fastify, Zod, Tailwind, PostgreSQL 16, Redis, MinIO e Mailpit.

**Spec:** `docs/superpowers/specs/2026-10-17-avl-166-design.md`

## Global Constraints

- Preservar todo código e dado legado.
- Não usar Odoo.
- Não publicar n8n nem fazer deploy.
- Segredos somente por variáveis/credenciais externas.

## Review Focus

- Falha rápida quando variáveis obrigatórias estão ausentes.
- Isolamento de portas e nomes entre os seis apps.
- Inicialização idempotente do Postgres e extensões.
- Navegação por teclado, foco e layout sem overflow mobile.
- Build reproduzível sem serviços externos.
